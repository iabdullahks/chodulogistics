PHASE 2 – ADMIN REQUIREMENTS
====================================================

Before writing any code, generate a complete Admin Requirements Document.

For every frontend section explain:

• What data needs to be stored
• Which database table should store it
• Which API should manage it
• Which admin page should edit it
• How changes should instantly appear on the frontend

Nothing on the frontend should require editing source code.

Everything should be editable from the Admin Portal.

====================================================

====================================================

Explain how the entire system works.

For every feature describe the complete data flow.

Example:

↓

Shipment is saved in the database

↓

Backend API updates the record

↓

Frontend calls the tracking API

↓

Customer enters Tracking Number

↓

Latest shipment status is displayed

Do the same for every feature including:

• Services
